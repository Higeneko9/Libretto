# Privacy Policy

Libretto is a local application. It does not collect, transmit or sell personal data.

- **No telemetry or analytics.** Libretto does not phone home, check for updates, or send usage data to the author or any third party.
- **Network access.** The only connection Libretto makes is to the ComfyUI server address you configure (by default on your own machine or local network), to send prompts and fetch generated images.
- **Your data stays with you.** Libraries, scenes, snapshots, settings and generated images are stored in a folder on your computer (`ugc/`, or the application data folder for the desktop app). Nothing is uploaded.
- **Accounts.** Libretto has no accounts or sign-in.

If you open a GitHub issue or discussion, GitHub's own privacy policy applies to what you post there.

Questions: open an issue at https://github.com/Higeneko9/Libretto/issues.
